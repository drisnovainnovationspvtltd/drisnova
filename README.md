# DRISNOVA — Official Website
**Drisnova Innovation Pvt Ltd**  
*Engineering Vision. Empowering Automation.*

Official repository for DRISNOVA, an industrial technology and engineering company delivering intelligent machine vision, AI-powered inspection, and robotics integration solutions for modern manufacturing industries.

---

## 🌟 Overview & Key Capabilities

- **Industrial Machine Vision Systems:** Rule-based and smart cameras (Cognex, Keyence, Omron, Hikvision)
- **AI-Based Vision Inspection:** Deep learning surface defect detection and classification
- **Robotic Vision Integration:** FANUC Robotics and Mech-Mind 3D bin-picking guidance
- **Vision System Programming & Tuning:** Custom toolchains, PLC handshakes, and cycle-time optimization
- **Installation & Commissioning:** Optics setup, specialized illumination, and validation
- **GR&R & Capability Studies:** Repeatability and reproducibility statistical verification
- **Troubleshooting & Retrofit:** Upgrade legacy camera systems without complete line overhaul
- **Industrial Vision Training & Consultation:** Practical industrial upskilling and feasibility studies

## 🚀 Getting Started

No build tools or package managers required. Simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/yashpatil7224/Drisnova.git
cd Drisnova
# Optional: run a local server
python -m http.server 3000
```
